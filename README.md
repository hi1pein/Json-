# Pl3xMap SSE Client

Python клиент для получения данных с карты Minecraft в реальном времени через Server-Sent Events (SSE). Совместим с картами Pl3xMap и его форками (например, Suzeren).

## 🚀 Возможности

- Автоматическое определение SSE-эндпоинта.
- Автоматическое переподключение при обрыве связи.
- Кеширование последних данных для мгновенного доступа.
- Синхронная и асинхронная версии.
- Легко интегрируется в ботов (Discord, Telegram, Aiogram и др.).
- Настраиваемое логирование.
- Поддержка переменных окружения.
